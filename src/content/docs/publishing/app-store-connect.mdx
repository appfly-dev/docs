App Store Connect is a separate connection from importing a public App Store listing. Open your app’s store connection settings and follow the setup shown there.

You can import a listing on Free. Sending screenshots, previews, and listing text requires Solo or Pro. Some advanced store tools require Pro; see [plans](/account/plans).

## Prepare a release

1. Connect the correct app.
2. Choose an editable version in App Store Connect.
3. Review screenshot sizes, languages, preview videos, and listing text.
4. Send the supported changes from Appfly.
5. Open App Store Connect, review the release, and submit it yourself.

If a version is not editable, choose or create an editable version through Apple before sending changes.

## What MCP does

The MCP server can generate and export launch assets. It does not register tools for publishing a store release or submitting an app for review.

Use the browser store tools for supported App Store Connect operations. Check the app’s messages if a connection, permission, or version state blocks an update.
