Use the account pages to review your profile, sessions, and developer connections.

## API keys

Open **Developer API** to create a named key for an agent. The full key is shown only when you create it. Store it in the client’s private configuration.

Keys are account-wide rather than limited to one app. They can let an agent use your apps and credits. Revoke keys you no longer use.

## OAuth connections

When a client supports OAuth, you can connect by signing in and authorizing the client. Review connected tools in Developer API and revoke connections you no longer need.

## Sessions

Review sessions in your account if you need to check where you are signed in. Use the account controls for ending sessions or changing your profile.

For an authentication problem, see [MCP troubleshooting](/ai/troubleshooting). For support, contact [hello@appfly.dev](mailto:hello@appfly.dev) without sending keys or passwords.
