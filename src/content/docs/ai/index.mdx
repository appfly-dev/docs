Appfly uses AI to help draft layouts, headlines, translations, and other launch assets. You can also connect an agent through the MCP server.

## In the browser

Add useful app details and choose the generation controls in an editor. Review the result before exporting. AI work uses credits, and some features require a paid plan.

## Through your agent

MCP lets a compatible client use Appfly’s tools in your account. The agent can create screenshot sets and videos, edit project text, add languages, and export files.

Start with [MCP setup](/ai/mcp). You can connect by [signing in with OAuth](/ai/mcp-oauth) or with an [API key](/ai/mcp-api-key). Then try the [example workflows](/ai/workflows). The [tool reference](/api/tools) lists the supported operations.

An agent uses your account’s apps, assets, plan limits, and credits. Ask it to check the account first and explain a larger generation before starting.
