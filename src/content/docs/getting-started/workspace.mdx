An **app** is the workspace for one product. Its screenshots, videos, uploaded files, and store connection stay together.

A **project** is something you edit, such as a screenshot set or promo video. You can make more than one project for an app, for example a new set for your next release.

An **asset** is a file you upload or import, such as an app screen, recording, or icon. A project can use several assets.

## Add an app

Open **All apps**, choose **New app**, and enter the app details. Give Appfly a short description of what the app does and who it is for. These details help AI generation write more useful text.

Use the app switcher to change workspaces. Check the selected app before uploading files or creating a project.

## Find a tool

Inside an app, the sidebar gives you access to Screenshots, Promo Video, Mockups, Graphics, ASO Copy, App Icons, and Websites. Store tools and account features have their own pages.

Your plan limits how many apps you can keep. See [plans](/account/plans).
