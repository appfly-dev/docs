Open **ASO Copy** to work on the text for your store listing. Start with your app details, generate a draft if useful, then edit it yourself.

## Review a draft

Check the title, description, and other listing fields. Replace vague claims with a clear description of what the app does. Confirm that the text matches the current app release.

## Translate a project

On Solo or Pro, you can add languages to screenshot text. Review the wording and layout for each language before exporting. Translated text may take more space than the English version.

On Pro, you can also ask [Appfly AI](/ai/chat) in the chat to translate a project ("Translate my newest project into German") or to shorten its headlines.

MCP translation uses `translate_project`. English is the base language and cannot be removed. Call the tool once for each new language. The agent can use `set_text` to edit individual text layers in a selected language.

Listing copy in the browser and screenshot project text through MCP are different workflows. The MCP server does not expose a general listing-copy generation tool.
