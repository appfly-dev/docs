Open your app and choose **Screenshots**. Create a project from uploaded screens or start with a template.

## Build the set

1. Add the screens you want to show.
2. Choose a phone or tablet canvas size.
3. Pick a template and arrange the screens.
4. Add a short headline for each feature.
5. Adjust device frames, backgrounds, colors, and spacing.

Use one clear message per screenshot. Put the main benefit near the start of the set, and check that text is readable at listing size.

## Edit the result

Select an element to change its properties. Keep important parts of your app screen visible inside the device frame. Review the full set together so the colors and spacing feel consistent.

You can [translate the text](/tools/copy-translations) on a paid plan, then export the device sizes and languages you need.

## Ask your agent

> Make App Store screenshots from my uploaded screens. Use pink accents and short headlines.

The MCP tools can create the project, change its template, edit text, and export it. Read the [screenshot workflow](/ai/workflows) before running a larger generation.
