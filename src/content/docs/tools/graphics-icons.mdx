Use **Graphics** for social images, ads, and other visuals around your app. Use **App Icons** when you want to work on an icon design.

## Make a graphic

Choose the format for the place you will use the image. Add app screens, device frames, text, and background elements. Review the image at its final size before export.

## Work on an icon

Add a description of your app and the look you want. Use AI to try a design, then review the result in the editor. Keep the icon readable at a small size.

AI image generation uses credits. Your plan also limits how many icons you can keep for an app.

## MCP availability

The registered MCP tools currently focus on screenshots, videos, project text, translation, and export. They do not include website creation or app icon generation. Use these editors in the browser.

For supported agent tasks, see [MCP tools](/api/tools).
